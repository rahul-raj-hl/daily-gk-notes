# 📌 Jatis of Indian Classical Ragas

## ⚡ Quick Summary

- A **Raga (melodic framework or tune)** is the foundation of Indian Classical Music.
- Ragas are classified into **Jatis (categories)** based on the **number of musical notes (Swaras)** used.
- There are **3 main Jatis**.
- SSC usually asks **Jati ↔ Number of Notes**.
- Remember: **5 - 6 - 7 Notes**.

---

## 📖 Main Concept

### What is a Raga?

*A Raga is a fixed pattern of musical notes that creates a particular mood.*

- Used in **Hindustani** and **Carnatic** classical music.
- Made from **Swaras (Musical Notes)**.
- There are **7 basic Swaras**:
  - Sa
  - Re
  - Ga
  - Ma
  - Pa
  - Dha
  - Ni

---

### What is a Jati?

*Jati means a category (classification) of a raga based on the number of notes used.*

There are **3 main Jatis**:

#### Audav (Audava)

*Uses **5 notes (Swaras)**.*

- Number of notes: **5**
- Example: Bhupali

---

#### Shadav (Shadava)

*Uses **6 notes (Swaras)**.*

- Number of notes: **6**
- One note is omitted.

---

#### Sampurna

*Uses all **7 notes (Swaras)**.*

- Number of notes: **7**
- Uses all seven basic swaras.

---

## ⚠️ Frequently Confused

| Term | Meaning |
|------|---------|
| Swara | A musical note (Sa, Re, Ga, Ma, Pa, Dha, Ni) |
| Raga | A melodic framework made using swaras |
| Jati | Classification of a raga based on the number of notes |
| Tala | Rhythmic cycle (beat pattern), not a raga |

---

## 🎯 Memory Trick

### 🎵 **"A-S-S = 5-6-7"**

- **A**udav → **5** notes
- **S**hadav → **6** notes
- **S**ampurna → **7** notes

👉 **A-S-S → 5-6-7**
