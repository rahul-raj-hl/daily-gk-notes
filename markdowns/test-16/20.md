# 📌 Electrical Quantities & SI Units

## ⚡ Quick Summary

- **Correct Matching**: **i - d, ii - c, iii - b, iv - a**
- **Electric Current**: Measured in **Ampere ($\text{A}$)** — defined as the rate of flow of electric charge ($I = Q/t$).
- **Potential Difference**: Measured in **Volt ($\text{V}$)** — work done per unit charge in moving it between two points ($V = W/Q$).
- **Capacitance**: Measured in **Farad ($\text{F}$)** — ability of a system to store electrical charge per unit potential difference ($C = Q/V$).
- **Inductance**: Measured in **Henry ($\text{H}$)** — property of a conductor by which a change in current induces an electromotive force ($e = -L \frac{dI}{dt}$).

---

## 📖 Main Concept

### 1. Detailed Breakdown of Quantities & Definitions

*Formulas, base units, and SI derivations:*

| Physical Quantity | SI Unit | Symbol | Governing Formula | Equivalent Units |
| :--- | :--- | :---: | :--- | :--- |
| **Electric Current** | **Ampere** | $\text{A}$ | $I = \frac{Q}{t}$ | $\text{Coulomb/second } (\text{C}\cdot\text{s}^{-1})$ |
| **Potential Difference** | **Volt** | $\text{V}$ | $V = \frac{W}{Q} = I R$ | $\text{Joule/Coulomb } (\text{J}\cdot\text{C}^{-1})$ |
| **Capacitance** | **Farad** | $\text{F}$ | $C = \frac{Q}{V}$ | $\text{Coulomb/Volt } (\text{C}\cdot\text{V}^{-1})$ |
| **Inductance** | **Henry** | $\text{H}$ | $L = \frac{\Phi}{I} = \frac{e}{|dI/dt|}$ | $\text{Volt}\cdot\text{second/Ampere } (\text{V}\cdot\text{s}\cdot\text{A}^{-1}) = \text{Wb/A}$ |

---

### 2. Connected Electrical Quantities and Units

- **Electric Charge ($Q$)**: Measured in **Coulomb ($\text{C}$)** or $\text{Ampere-second } (\text{A}\cdot\text{s})$.
- **Electrical Resistance ($R$)**: Measured in **Ohm ($\Omega = \text{V/A}$)**.
- **Electrical Resistivity ($\rho$)**: Measured in **Ohm-meter ($\Omega\cdot\text{m}$)**.
- **Electrical Conductance ($G$)**: Measured in **Siemens ($\text{S}$)** or $\text{mho} \ (\Omega^{-1})$.
- **Electrical Conductivity ($\sigma$)**: Measured in **Siemens per meter ($\text{S/m}$)**.
- **Magnetic Flux ($\Phi$)**: Measured in **Weber ($\text{Wb} = \text{V}\cdot\text{s}$)**.

## ⚠️ Frequently Confused

| Unit | Measures | Common Confusion |
| :--- | :--- | :--- |
| **Farad ($\text{F}$)** | **Capacitance** | Confused with **Faraday** (Unit of electric charge: $1\text{ Faraday} \approx 96,500\text{ C}$) |
| **Henry ($\text{H}$)** | **Inductance** | Confused with **Hertz** (Frequency) |
| **Volt ($\text{V}$)** | **Electric Potential / EMF** | Confused with **Watt** (Electrical Power) |
| **Siemens ($\text{S}$)** | **Conductance** | Confused with **Tesla** (Magnetic Field) |

### Q3

The dimensional formula for Inductance ($L$) is:

- [x] $[\text{M}^1 \text{L}^2 \text{T}^{-2} \text{A}^{-2}]$
- [ ] $[\text{M}^1 \text{L}^1 \text{T}^{-2} \text{A}^{-1}]$
- [ ] $[\text{M}^0 \text{L}^2 \text{T}^{-2} \text{A}^{-1}]$
- [ ] $[\text{M}^1 \text{L}^2 \text{T}^{-3} \text{A}^{-1}]$

> Since Energy $E = \frac{1}{2}LI^2 \implies L = \frac{2E}{I^2} = \frac{[\text{M}\text{L}^2\text{T}^{-2}]}{[\text{A}^2]} = [\text{M}\text{L}^2\text{T}^{-2}\text{A}^{-2}]$.
