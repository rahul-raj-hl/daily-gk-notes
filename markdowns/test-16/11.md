# 📌 Census 2011: Population Rankings & Least Populous States

## ⚡ Quick Summary

- **Correct Answer**: **Mizoram**.
- **Least Populous State (Rank 1 from bottom)**: **Sikkim** ($\approx 6.10\text{ Lakh}$ / $610,577$).
- **Second Least Populous State (Rank 2 from bottom)**: **Mizoram** ($\approx 10.97\text{ Lakh}$ / $1,097,206$).
- **Third Least Populous State (Rank 3 from bottom)**: **Arunachal Pradesh** ($\approx 13.84\text{ Lakh}$ / $1,383,727$).
- **Fourth Least Populous State (Rank 4 from bottom)**: **Goa** ($\approx 14.58\text{ Lakh}$ / $1,458,545$).
