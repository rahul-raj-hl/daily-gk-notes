# 📌 Common Sodium Compounds & Their Uses

## ⚡ Quick Summary

- **Baking Soda**: Chemical Name is **Sodium Bicarbonate** ($\text{NaHCO}_3$); used as a leavening agent in baking and as an antacid.
- **Washing Soda**: Chemical Name is **Sodium Carbonate Decahydrate** ($\text{Na}_2\text{CO}_3 \cdot 10\text{H}_2\text{O}$); used for cleaning and softening hard water.
- **Common Salt**: Chemical Name is **Sodium Chloride** ($\text{NaCl}$); essential table salt and preservative.
- **Food Preservatives**: **Sodium Benzoate** ($\text{C}_6\text{H}_5\text{COONa}$) is a widely used food and pickling preservative (E-number E211).
- **Flavor Enhancer**: **Monosodium Glutamate (MSG)** ($\text{C}_5\text{H}_8\text{NO}_4\text{Na}$); sodium salt of glutamic acid used to impart umami flavor.

## 🧠 Exam Booster

| Strategic Point | Fact / Information |
| :--- | :--- |
| **Solvay Process** | Industrial process used to manufacture **Sodium Carbonate** ($\text{Na}_2\text{CO}_3$) using ammonia and brine ($\text{NaCl}$). |
| **Action of Heat on Baking Soda** | $2\text{NaHCO}_3 \xrightarrow{\Delta} \text{Na}_2\text{CO}_3 + \text{H}_2\text{O} + \text{CO}_2\uparrow$ (Released $\text{CO}_2$ makes cakes soft and spongy). |
| **Baking Powder vs Baking Soda** | Baking powder = **Baking Soda ($\text{NaHCO}_3$) + mild edible acid** (e.g., Tartaric Acid). |
| **Sora / Saltpetre Trap** | **Chile Saltpetre** is Sodium Nitrate ($\text{NaNO}_3$), whereas **Indian Saltpetre** is Potassium Nitrate ($\text{KNO}_3$). |

## ⚠️ Frequently Confused

| Common Name | Chemical Formula | Key Difference |
| :--- | :--- | :--- |
| **Baking Soda** | **$\text{NaHCO}_3$** | Contains Hydrogen (Sodium **Hydrogen** Carbonate). |
| **Washing Soda** | **$\text{Na}_2\text{CO}_3 \cdot 10\text{H}_2\text{O}$** | Contains **10 molecules of water of crystallization**. |
| **Soda Ash** | **$\text{Na}_2\text{CO}_3$** | Anhydrous Sodium Carbonate (Washing Soda without water). |

## 🎯 Memory Trick

> **Mnemonic: "Baking = Bye-Bye Acid (Bicarbonate)"**
> - **B**aking Soda has **B**icarbonate ($\text{NaHCO}_3$).
> - **W**ashing Soda has **Water** of crystallization ($\text{Na}_2\text{CO}_3 \cdot \mathbf{10H_2O}$).
