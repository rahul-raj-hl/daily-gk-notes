# 📌 ABHYAS: High-Speed Expendable Aerial Target (HEAT)

## ⚡ Quick Summary

- **Developer**: **Aeronautical Development Establishment (ADE)**, a laboratory of **DRDO** (Defence Research and Development Organisation).
- **Core Role**: Serves as a realistic **High-Speed Expendable Aerial Target (HEAT)** to test, evaluate, and calibrate various surface-to-air (SAM) and air-to-air missile systems, radars, and weapon tracking networks.
- **Propulsion**: Driven by a small **gas turbine engine** and launched using twin solid-rocket boosters.
- **Flight & Navigation**: Reaches speeds up to **0.5 Mach** and utilizes a MEMS-based **Inertial Navigation System (INS)** with Flight Control Computer (FCC) for fully autonomous flight path navigation.

## 📖 Key Specifications & Features Matrix

### 1. Technological Architecture

| Component | Technical Feature | Functional Importance |
| :--- | :--- | :--- |
| **Type** | HEAT (Expendable Drone/Target) | Simulates hostile aerial targets during missile firing trials. |
| **Propulsion Unit** | Gas Turbine Engine | Provides sustained cruise capability at subsonic speed (~0.5 Mach). |
| **Launch Mechanism** | Twin Solid Rocket Boosters | Provides initial thrust to launch from a static ground launcher. |
| **Navigation System** | MEMS-based INS + GPS/A-GPS | Ensures precise pre-programmed waypoint navigation during trials. |
| **Airframe Material** | Lightweight Composite Materials | Enhances aerodynamic efficiency and structural strength. |

---

### 2. Operational Roles & Equipment

| Feature | Description |
| :--- | :--- |
| **Acoustic & Radar Signatures** | Equipped with **Radar Cross Section (RCS) augmenters** and **Luneberg Lenses** to simulate larger incoming enemy aircraft or missiles. |
| **Autonomous Flight** | Uses a ground control station (GCS) for telemetry tracking while executing autonomous flight profiles. |
| **Cost Efficiency** | Offers a lower-cost indigenous alternative to importing aerial target systems (like Lakshya / foreign drones). |
