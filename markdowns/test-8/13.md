# 📌 Scientific Measuring Instruments & Applications

## ⚡ Quick Summary

- **Photometer**: Instrument used to measure **light intensity** (luminous intensity) or optical absorption of light across the visible and electromagnetic spectrum.
- **Ammeter**: Measures **electric current** in amperes ($A$) and is always connected in **series** in a circuit (ideal ammeter resistance = $0$).
- **Dynamometer**: Measures mechanical **force, torque, or power** produced by an engine/motor.
- **Calipers**: Precision tools used to measure physical dimensions such as **length, depth, internal/external diameters**.

## 🧠 Exam Booster

| Strategic Point | Fact / Information |
| :--- | :--- |
| **Conversion of Galvanometer to Ammeter** | Connect a **low resistance (Shunt)** in **parallel** with the galvanometer. |
| **Conversion of Galvanometer to Voltmeter** | Connect a **high resistance** in **series** with the galvanometer. |
| **SI Unit of Luminous Intensity** | **Candela ($cd$)** — one of the 7 fundamental SI base units. |
| **SI Unit of Illuminance** | **Lux ($lx$)**, where $1\text{ Lux} = 1\text{ Lumen/m}^2$. |

## ⚠️ Frequently Confused

| Instrument A | Instrument B | Core Distinguishing Feature |
| :--- | :--- | :--- |
| **Hydrometer** | **Hygrometer** | **Hydrometer** = Liquid density; **Hygrometer** = Atmospheric humidity. |
| **Ammeter** | **Voltmeter** | **Ammeter** = Series connection (low resistance); **Voltmeter** = Parallel connection (high resistance). |
| **Photometer** | **Pyrometer** | **Photometer** = Light intensity; **Pyrometer** = Ultra-high temperatures. |

How is an Ammeter connected in an electric circuit to measure current flowing through a component?

- [x] In Series
- [ ] In Parallel
